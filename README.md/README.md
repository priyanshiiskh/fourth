## 📊 Projects

### 1. International Sales Dashboard - Tableau
This Tableau International Sales Dashboard tracks global performance for the last 12 months across 48 countries, showing $24.8M sales, 186K orders, $133.33 average order value, and $6.7M profit. It visualizes sales by country, monthly trend, top countries, product categories, and regional performance with filters.

**Key Insights:**
- Total Sales: $24.8M (+12.5% vs PY)
- Total Profit: $6.7M (+15.1% vs PY)
- Top Country: USA - $3.5M
- Top Category: Technology - 37.6%
